# Sabado 한국어 패치

Sabado의 대사·메뉴·일부 안내 이미지를 한국어로 바꾸는 비공식 패치입니다. 별도 프로그램 설치 없이 사용할 수 있습니다.

**지원:** Windows 10/11 Steam판 · Full Version 1.0.1 (build 26402944)

## 다운로드

**[최신 패치 받기](https://github.com/o-tantk/sabado-kr-patch/releases/latest)** → `SabadoKorean-v0.1.6-windows-x64.zip`을 받으세요.

## 설치

1. 게임을 종료하고 ZIP을 **모두 압축 풀기** 합니다.
2. **`설치.bat`**를 더블클릭하고 자동으로 찾은 게임 폴더를 확인합니다.
3. 완료되면 Steam에서 게임을 실행하고 텍스트 언어를 **한국어**로 선택합니다. `English`로 표시되면 같은 항목입니다.

게임을 찾지 못한 경우에만 `Sabado Day One.exe`를 선택하는 창이 열립니다. 위치는 Steam에서 Sabado 우클릭 → **관리 → 로컬 파일 탐색**으로 확인할 수 있습니다. 관리자 권한 요청이 나오면 승인해 주세요.

## 업데이트와 복구

- **업데이트:** 새 ZIP을 새 폴더에 풀고 `설치.bat`를 실행합니다.
- **패치 제거 / 원상 복구:** 게임을 종료하고 `복구.bat`를 실행합니다.
- **설치 중 중단됨:** `복구.bat`로 원래 상태로 돌린 뒤 다시 설치합니다.

배포 폴더를 지웠다면 다시 받아 제거할 수 있습니다. 게임 폴더를 옮길 때는 먼저 패치를 제거해 주세요.

작업 중에는 배치 파일 옆에 임시 백업 ZIP이 생성되고, 성공하면 자동으로 삭제됩니다. 실패하거나 중단되면 백업을 보관한 채 `복구.bat`를 실행해 주세요.

아직 모든 장면을 검수한 완성판은 아니며, 일부 영문이나 표시 문제가 남아 있을 수 있습니다. 다른 게임 버전이나 모드와의 호환은 보장하지 않습니다.
