# Sabado 한국어 패치

Windows Steam판 **Sabado**를 한국어로 플레이할 수 있게 하는 비공식 패치입니다. 대사·목표·메뉴와 캐릭터·아이템 이름, 일부 안내 이미지를 번역합니다.

**현재 배포 버전: 0.1.4** · Python 설치 없이 배치 파일을 더블클릭해 설치하고 제거할 수 있습니다.

## 다운로드

**[최신 한국어 패치 다운로드](https://github.com/o-tantk/sabado-kr-patch/releases/latest)**

릴리스의 Assets에서 **`SabadoKorean-v0.1.4-windows-x64.zip`**을 받으세요. GitHub가 자동으로 제공하는 `Source code (zip)`과 `Source code (tar.gz)`는 개발용 소스이며 설치용 패키지가 아닙니다.

## 지원 환경

- Windows 10 / 11, 64비트 Steam판 Sabado
- 지원 게임 버전: **Full Version 1.0.1 / Steam build 26402944** (App ID 4986750)
- Windows 기본 **맑은 고딕** 글꼴. 글꼴이 없으면 Windows 언어 설정에서 한국어 글꼴을 추가해 주세요.

Python, Unity Editor, Git, 별도 모드 로더를 설치할 필요가 없습니다. 필요한 BepInEx 로더는 배포 ZIP에 포함되어 있으며 설치 중 인터넷 연결도 필요하지 않습니다. Windows 기본 PowerShell을 사용합니다.

게임 버전이 다르면 설치 전에 중단합니다. 다른 모드 로더와의 자동 병합은 지원하지 않습니다.

## 설치

1. Sabado를 완전히 종료합니다.
2. 내려받은 ZIP을 우클릭해 **모두 압축 풀기**를 선택합니다. ZIP 안에서 바로 실행하지 마세요. 게임 폴더 밖의 원하는 위치에 풀면 됩니다.
3. 압축을 푼 폴더의 **`설치.bat`**를 더블클릭합니다.
4. 자동으로 찾은 게임 폴더를 확인하고 **예**를 누릅니다. 폴더가 다르면 **아니요**를 눌러 올바른 `Sabado Day One.exe`를 선택합니다. 자동으로 찾지 못해도 파일 선택 창이 열립니다.
5. 게임 폴더에 관리자 권한이 필요한 경우 Windows 권한 요청을 승인한 뒤, 새로 열린 안내 창에서 진행합니다. 완료 메시지가 나올 때까지 기다립니다.
6. Steam에서 게임을 실행하고 **텍스트 언어를 한국어**로 선택합니다. 이전 표시가 남아 있으면 **English**가 같은 슬롯입니다. 음성 언어는 원하는 기존 언어로 설정하세요.

`설치.bat`와 함께 들어 있는 `installer`, `payload`, `package.json`은 한 폴더에 그대로 두세요. 개별 파일을 게임 폴더로 복사할 필요가 없습니다.

## 업데이트

게임을 종료하고 새 버전 ZIP을 **새 폴더에** 모두 푼 뒤 `설치.bat`를 실행하면 됩니다. 이전 설치 기록을 읽어 업데이트하며 최초 설치 전 상태로 돌아갈 백업도 유지합니다. 기존 Python 도구로 설치한 0.1.3 패치도 지원합니다.

직접 수정한 패치 파일이 있으면 덮어쓰지 않고 중단합니다. 해당 파일을 별도로 보관한 뒤 원래 배포 파일로 되돌려 주세요.

## 제거

1. 게임을 완전히 종료합니다.
2. 압축을 풀었던 배포 폴더에서 **`제거.bat`**를 더블클릭합니다.
3. 게임 폴더를 확인하고 진행합니다. 제거 완료 메시지가 나오면 끝입니다.

배포 폴더를 지웠다면 ZIP을 다시 받아 풀고 `제거.bat`를 실행해도 됩니다. 제거에는 `payload`의 설치 파일이 필요하지 않습니다.

설치 전에 존재하던 파일은 백업으로 복원하고, 패치가 추가한 관리 파일만 제거합니다. **세이브와 게임 설정은 유지됩니다.** BepInEx가 생성한 로그·캐시·설정, 빈 폴더와 복구 백업은 남을 수 있지만 패치 로더는 제거됩니다.

## 문제가 생겼을 때

| 증상 | 해결 방법 |
| --- | --- |
| 게임 폴더를 못 찾음 | Steam 라이브러리에서 Sabado 우클릭 → 관리 → 로컬 파일 탐색. 그 폴더의 `Sabado Day One.exe`를 선택하세요. |
| 지원하는 게임 버전과 다르다고 나옴 | 이 패치는 build 26402944 전용입니다. 게임이 업데이트되었다면 대응 패치가 필요합니다. 원본 파일을 수정했다면 먼저 복원하세요. |
| 게임이 실행 중이라고 나옴 | 게임을 완전히 종료하고 다시 실행하세요. 설치 도구가 게임을 강제로 종료하지는 않습니다. |
| 파일이 없거나 변경되었다고 나옴 | ZIP 전체를 새 폴더에 다시 풀어 보세요. 설치된 파일을 직접 수정했다면 그 파일을 보관하고 원래 배포 파일로 복원한 뒤 재시도하세요. |
| 설치·제거 중 전원이 꺼짐 / 중단 작업 메시지 | 게임을 실행하지 말고 **`복구.bat`**를 먼저 실행하세요. 작업 직전 상태로 복구한 다음 설치 또는 제거를 다시 실행합니다. |
| 글자가 네모로 나옴 | Windows에 맑은 고딕이 설치되어 있는지 확인하세요. |
| 회사·학교 PC에서 스크립트가 차단됨 | 조직 정책이 실행을 제한할 수 있습니다. 관리자에게 문의하세요. 시스템 전체 실행 정책을 바꿀 필요는 없습니다. |

백업은 `%LOCALAPPDATA%\SabadoKorean\Backups`에 보관합니다. 설치 상태에서는 이 백업과 게임 폴더의 `SabadoKorean.install.json`을 삭제하지 마세요. 게임 폴더를 옮길 때는 **먼저 패치를 제거하고 이동한 위치에 다시 설치**하세요. 기존 Python 설치본에서 업데이트하기 전에는 기존 `local/backups`도 유지해 주세요.

문제를 제보할 때는 [Issues](https://github.com/o-tantk/sabado-kr-patch/issues)에 게임 버전, 패치 버전, 오류 메시지와 문제가 나온 장면을 알려 주세요.

## 번역 범위와 확인 상태

- 대사·목표·튜토리얼 등 영어 고유 키 **493개**
- 캐릭터·아이템 이름, 챕터 선택, 상호작용 안내 등 추가 UI **133개**
- 문에 붙은 이동 안내 메모와 튜토리얼 그림 **4개**

전체 장면을 검수한 완성판은 아닙니다. 문 메모의 게임 내 표시와 언어 전환은 확인했지만, 튜토리얼 이미지 3개의 실제 화면, 모든 챕터·해상도·긴 대사의 줄바꿈은 추가 검수가 필요합니다. 배경의 모든 영문 이미지를 번역한 것도 아닙니다. 음성은 번역하지 않습니다.
