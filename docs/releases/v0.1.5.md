# Sabado 한국어 패치 v0.1.5

게임 폴더 자동 탐색 문제를 수정하고 사용 안내를 간단히 정리했습니다.

**지원:** Windows 10/11 Steam판 · Full Version 1.0.1 (build 26402944)

1. 아래 **`SabadoKorean-v0.1.5-windows-x64.zip`**을 받습니다.
2. 게임을 종료하고 ZIP을 **모두 압축 풀기** 합니다.
3. **`설치.bat`**를 실행하고 안내에 따라 진행합니다.
4. 게임에서 텍스트 언어를 **한국어**로 선택합니다.

제거하려면 게임을 종료하고 **`제거.bat`**를 실행하세요. 세이브는 유지됩니다.

[자세한 사용 방법](https://github.com/o-tantk/sabado-kr-patch#설치)
