# Sabado 한국어 패치 v0.1.4

Python 없이 설치하고 제거할 수 있는 Windows 배포판입니다.

## 다운로드 및 설치

1. 아래 Assets의 **`SabadoKorean-v0.1.4-windows-x64.zip`**을 받습니다. `Source code`는 설치용 파일이 아닙니다.
2. ZIP을 게임 폴더 밖에 **모두 압축 풀기** 합니다.
3. 게임을 종료하고 **`설치.bat`**를 더블클릭합니다.
4. 게임 폴더를 확인하고 진행합니다. 관리자 권한 요청이 나오면 승인 후 새 안내 창에서 진행합니다.
5. Steam에서 게임을 시작하고 텍스트 언어를 **한국어**로 선택합니다. `English`로 표시되면 같은 슬롯입니다.

제거는 게임을 종료한 뒤 **`제거.bat`**를 실행하세요. 작업이 중단되었다면 **`복구.bat`**로 이전 상태를 복원한 뒤 다시 진행할 수 있습니다.

## 이번 변경

- Windows 기본 PowerShell로 실행하는 설치·제거·복구 배치 파일
- Steam 게임 폴더 자동 탐색 및 게임 실행 파일 선택 창
- 기존 0.1.3 Python 설치본 업데이트 지원, 배포 폴더와 분리된 백업
- 설치·제거 실패 시 이전 상태 복원, 중단 작업 재복구
- 일반 사용자용 README 및 ZIP 안의 사용설명서

## 지원 범위

**Windows 10/11 64비트 Steam판, Full Version 1.0.1 / build 26402944** 전용입니다. 맑은 고딕이 필요합니다. 게임 버전이나 관리 파일이 다르면 설치 전에 중단합니다. 다른 모드 로더와 자동 병합하지 않습니다.

대사·목표 등 493개 키, 추가 UI 133개, 안내 이미지 4개를 번역합니다. 번역 범위는 0.1.3과 같습니다. 전체 장면·해상도와 튜토리얼 이미지 3개의 게임 내 표시는 아직 검수를 마치지 않았습니다. 음성은 번역하지 않습니다.

## 검증

Windows PowerShell 5.1 설치/복구 시나리오 16개, 기존 Python 검사 12개와 C# 표시 검사 16개를 통과했습니다. Python을 PATH에서 제외한 상태에서 실제 게임 파일 복사본의 기존 패치 업데이트·제거·새 설치를 확인했고, 검사한 원본 7개의 SHA-256은 모두 유지됐습니다. 별도의 깨끗한 Windows VM 및 UAC 대화형 승인은 검증하지 않았습니다.

`SHA256SUMS.txt`는 설치 ZIP의 SHA-256입니다. BepInEx와 필요한 라이선스 및 UnityDoorstop 소스를 동봉하며 게임 원본이나 Windows 글꼴은 포함하지 않습니다.
